# Веб-приложение "Помощник бухгалтера"

## Общее описание

Система предназначена для помощи бухгалтеру в ежедневной работе: быстрый доступ к справочной информации, расчёт налогов и взносов, хранение шаблонов проводок.

## Основной положительный сценарий

1. Пользователь регистрируется или входит в свою учётную запись
2. Пользователь выбирает нужный раздел (например, "Калькулятор налогов")
3. Пользователь вводит необходимые данные (сумму, ставку налога)
4. Система производит расчёт и показывает результат
5. Пользователь может сохранить результат расчёта в историю
6. Позже пользователь может зайти в историю и посмотреть сохранённые расчёты
7. Пользователь также может воспользоваться справочником для быстрого поиска информации по налогам и проводкам

## Альтернативные сценарии

### Пользователь вводит некорректные данные
- Система не позволяет ввести буквы в числовые поля и подсвечивает поле с ошибкой

### Пользователь пытается выполнить расчёт с пустыми полями
- Система выдаёт сообщение "Заполните все обязательные поля" и не выполняет расчёт

## Пользовательские истории

### Вход в систему

**Я, как Пользователь, хочу входить в систему, чтобы получить доступ к своим данным.**

**Основной сценарий:**
1. Пользователь открывает приложение и видит форму входа
2. Пользователь вводит свой логин и пароль и нажимает кнопку "Войти"
3. Система проверяет данные и открывает главный экран приложения

**Альтернативные сценарии:**
- Пользователь вводит неверный логин или пароль. Система показывает сообщение об ошибке "Неверный логин или пароль"

### Расчёт налогов и взносов

**Я, как Пользователь, хочу рассчитывать налоги и взносы, чтобы быстро получать нужные суммы для работы.**

**Основной сценарий:**
1. Пользователь находится на главном экране и нажимает кнопку "Калькулятор"
2. Система открывает экран с выбором типа расчёта (НДС, налог на прибыль, страховые взносы)
3. Пользователь выбирает нужный тип расчёта
4. Система отображает поля для ввода данных (сумма, ставка)
5. Пользователь вводит данные и нажимает "Рассчитать"
6. Система показывает результат расчёта

### Сохранение результатов расчётов

**Я, как Пользователь, хочу сохранять результаты расчётов, чтобы вернуться к ним позже.**

**Основной сценарий:**
1. После выполнения расчёта пользователь видит кнопку "Сохранить"
2. Пользователь нажимает "Сохранить"
3. Система сохраняет расчёт с датой и временем в историю
4. Система показывает сообщение "Расчёт сохранён"

### Просмотр истории расчётов

**Я, как Пользователь, хочу просматривать историю своих расчётов, чтобы найти ранее выполненные вычисления.**

**Основной сценарий:**
1. Пользователь из главного меню переходит в раздел "История"
2. Система отображает список всех сохранённых расчётов в хронологическом порядке (от последнего к первому)
3. Пользователь нажимает на одну из записей в истории
4. Система открывает подробный экран с данными и результатом расчёта

### Справочник по налогам и проводкам

**Я, как Пользователь, хочу пользоваться справочником по налогам и проводкам, чтобы быстро находить необходимую информацию.**

**Основной сценарий:**
1. Пользователь из главного меню переходит в раздел "Справочник"
2. Система отображает список категорий (Налоги, Проводки, Отчётность)
3. Пользователь выбирает нужную категорию
4. Система показывает список тем в выбранной категории
5. Пользователь выбирает тему и читает справочную информацию

### Создание шаблонов проводок

**Я, как Пользователь, хочу создавать и сохранять шаблоны проводок, чтобы использовать их многократно.**

**Основной сценарий:**
1. Пользователь заходит в раздел "Шаблоны" и нажимает кнопку "Создать шаблон"
2. Система открывает форму с полями: "Название", "Дебет", "Кредит", "Описание"
3. Пользователь заполняет поля и нажимает "Сохранить"
4. Новый шаблон появляется в списке и доступен для использования

**Альтернативные сценарии:**
- Не заполнено обязательное поле "Название". Система не даёт сохранить шаблон и выводит ошибку "Введите название шаблона"
